# CONTAIN

탑뷰 2D 서바이벌 호러 로그라이크. Godot 4.6 (GDScript)으로 제작.

## 핵심 컨셉

- **HP = 1**: 체력은 단 하나. 대신 모든 행동(공격, 대시, 회피, 아이템 사용)이 스태미나를 소모하며, 스태미나 고갈이 곧 죽음으로 이어집니다.
- **전투 없음**: 지식, 은신, 자원 관리가 유일한 생존 수단. 회피와 은신 암살 위주의 플레이를 지향합니다.
- **공포 시스템**: 어둠 노출과 적 조우로 공포 수치가 오르며, 극한의 공포는 페널티인 동시에 하이 리스크-하이 리턴 기회(숨겨진 경로/아이템)로 작용합니다.
- **시야 통제**: 손전등/랜턴이 비추는 원뿔 안에서만 사물이 렌더링되어 쿼터뷰 특유의 사각지대 공포를 강조합니다.
- **로그라이트 진행**: 반복되는 죽음 속에서 지식 포인트(KP)를 모아 패시브/기술을 해금합니다.

## 기술 스택

- **엔진**: Godot 4.6
- **렌더링**: Forward Plus (D3D12, Windows)
- **물리**: Jolt Physics
- **플랫폼**: Windows Desktop / Web(WASM) export

## 프로젝트 구조

```
scenes/     게임 씬 및 스크립트 (플레이어, 적, 오브젝트, UI, 내러티브)
assets/     사운드 에셋 (BGM, 효과음)
scripts/    보조 스크립트
project.godot / export_presets.cfg
```

자세한 시스템 설명(적 AI, 맵 구조, 아이템/제작, 진행 시스템 등)은 [CLAUDE.md](CLAUDE.md)를, 기획 원안은 [\[게임 기획서\].md](%5B게임%20기획서%5D.md)를 참고하세요.

## 실행 방법

1. [Godot 4.6](https://godotengine.org/download) 설치
2. 프로젝트 폴더를 Godot에서 열기 (`project.godot`)
3. F5로 실행

빌드된 내보내기 결과물(`gamefile/`)은 저장소에 포함되어 있지 않습니다. `export_presets.cfg` 설정을 이용해 직접 내보내기(Export)하세요.
